# Дизайн-студия — Консольная информационная система

## Требования
- Java 17+
- PostgreSQL 14+
- Maven 3.8+

## Настройка базы данных
1. Создайте базу данных:
   CREATE DATABASE design_studio;
2. Выполните скрипт database.sql в базе design_studio.

## Настройка подключения
Откройте файл src/main/java/util/DatabaseManager.java
и укажите свои URL, USER, PASSWORD.

## Запуск
mvn clean compile exec:java

## Функции
- Управление клиентами (CRUD)
- Управление дизайнерами (CRUD)
- Управление дизайн-заказами (CRUD)
- Поиск (по названию, по описанию)
- Фильтрация (по статусу, по цене)
- Сортировка (по цене, по дате)
- Статистика
- Экспорт в Excel
